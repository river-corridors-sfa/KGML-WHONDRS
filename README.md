# S19S KGML Reproducible Workflow

This folder separates the original exploratory notebook into smaller, reproducible R Markdown workflows:

1. `01_process_data.Rmd`
   - Recreates the original upstream data processing from `S19S_sed_model_graph.Rmd`.
   - Reads raw S19S metadata, FTICR peak presence/absence, molecular formula, respiration, NPOC, biomass, sediment/water mass, and grain-size files.
   - Reads `S19S_sed_oxy.csv` as a precomputed thermodynamic-model output generated by `Thermodynamic_modeling.Rmd`.
   - Creates the FTICR sediment lookup table, matches thermodynamic results by row order, separates site IDs and positions, extracts miscellaneous sediment measurements, and regenerates `derived/up_all.csv`, `derived/mid_all.csv`, and `derived/low_all.csv`.
   - Writes `derived/s19s_sed_analysis_table.csv`.

2. `02_mechanistic_model.Rmd`
   - Reads the processed analysis table.
   - Builds mechanistic predictions and fitted/effective `Vh`.
   - Writes `derived/mechanistic_predictions.csv`.

3. `03_kgml_residual_learning.Rmd`
   - Reads mechanistic predictions and optional FTICR feature summaries.
   - Learns residual corrections with cross-validation.
   - Writes KGML result tables and figures.

4. `04_site_grouped_model_comparison.Rmd`
   - Reviewer-response workflow using grouped 5-fold CV and leave-one-site-out CV.
   - Compares mechanistic, linear, pure RF, pure XGBoost, KGML ablations, and KGML interaction models.

5. `05_interpretability_and_ablation.Rmd`
   - Creates permutation importance, SHAP-style local explanations through `iml`, and partial-dependence plots.
   - Specifically evaluates the accessibility terms and their interactions with the mechanistic prediction.

6. `06_fixed_vh0_sensitivity.Rmd`
   - Repeats grouped site-level KGML validation across fixed `Vh0` values.
   - Uses `0.05`, `0.1`, `0.25`, `0.5`, `1.0`, and the globally calibrated median reference.

7. `07_spatial_extrapolation.Rmd`
   - Adds spatially explicit holdouts using longitude bands and latitude/longitude clusters.
   - Tests whether models extrapolate to geographically distinct held-out regions.

Input files used by the workflow live in `raw_data/`. Shared helper functions and the shared PuOr figure palette live in `R/helpers.R`.

- `raw_data/WHONDRS_S19S_Sediment_GrainSize.csv`
- `raw_data/fticr_features.csv`

The thermodynamic input is:

- `raw_data/S19S_sed_oxy.csv`

This file is an upstream model output, not a raw measurement file. It is generated by `../Thermodynamic_modeling.Rmd` or the mirrored copy in `../FTICRMS_processed/Thermodynamic_modeling.Rmd`.

`01_process_data.Rmd` regenerates the matched peak-level sediment files as `derived/up_all.csv`, `derived/mid_all.csv`, and `derived/low_all.csv`. `fticr_features.csv` is used by the optional FTICR KGML section in `03_kgml_residual_learning.Rmd`. The metadata file also provides latitude/longitude for spatial extrapolation tests.

## Reproducibility Notes

- All derived outputs are written to `derived/`.
- Reviewer-facing figures are written to `figures/`.
- Data-processing QC figures use the `process_*.pdf` prefix.
- Cross-validation is seeded.
- Leakage-sensitive operations are kept inside fold loops where possible.
- Site-grouped cross-validation is used by default for KGML so upstream/midstream/downstream samples from the same site do not appear in both training and testing folds.
