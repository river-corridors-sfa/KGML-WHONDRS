# KGML-WHONDRS

#### Model inputs, outputs, and scripts associated with “Continental-scale controls on hyporheic respiration revealed by knowledge-guided machine learning”
Jianqiu Zheng, Vanessa A. Garayburu-Caruso, James C. Stegen, and Timothy D. Scheibe
## Summary
This data package is associated with the publication “Continental-scale controls on hyporheic respiration revealed by knowledge-guided machine learning” published in Environmental Research Communications (Zheng et al. 2026; DOI: [10.1088/2515-7620/ae9525](https://iopscience.iop.org/article/10.1088/2515-7620/ae9525/meta)). The project combines mechanistic process modeling with knowledge-guided machine learning (KGML) to evaluate how organic matter chemistry, microbial biomass, and physical substrate accessibility regulate realized respiration rates across river corridors. 

All data used in this paper have been previously published and can be accessed at https://data.ess-dive.lbl.gov/datasets/doi:10.15485/1729719 (Goldman et al., 2020). This data package contains the preprocessing scripts for the previously published data and subsequent modelling workflows. The full workflow with input and output data can be found in the associated GitHub repository athttps://github.com/river-corridors-sfa/KGML-WHONDRS.

A preliminary version of this data package was published in January 2026 at the time of manuscript submission. It was updated in August 2026, at the time of manuscript acceptance, to include additional metadata (this readme, data dictionary, and file level metadata) and include the final scripts that were revised during manuscript revisions. 

For details on how to navigate data packages generated by this project, see https://data.ess-dive.lbl.gov/portals/PNNLRiverCorridorSFA/About.
